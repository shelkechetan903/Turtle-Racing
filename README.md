# Turtle Race

A simple graphical turtle racing game built with Python Turtle.

## Features

- Interactive color selection
- Six colorful turtles
- Randomized turtle movement
- Automatic winner detection
- Win/Loss result displayed on the screen
- Simple graphical interface

## Technologies Used

- Python
- Turtle Graphics
- Random module

## How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python turtle-racing.py
```
